Данный репозиторий содержит строгую модульную архитектуру для массового извлечения наукометрических данных из неструктурированных аннотаций научных статей с использованием больших языковых моделей (LLM) и алгоритмической оптимизации DSPy. 

Методология полностью соответствует стандартам программной инженерии: вычислительная логика инкапсулирована, монолитные функции исключены, а конфигурации вынесены во внешний файл. Для обеспечения научной объективности внедрена строгая изоляция экзаменационной выборки от обучающей.

## 📁 Структура проекта

*   **`config.py`** — Единый конфигурационный файл. Содержит все API-ключи, гиперпараметры модели, настройки отказоустойчивости и абсолютные пути к файлам.
*   **`sampler.py`** — Скрипт предварительной подготовки. Случайным образом извлекает 60 статей (30 для эталона обучения, 30 для независимого экзамена), выводит их номера для ручной разметки в Excel и **физически удаляет** их из основной базы во избежание утечки данных (Data Leakage).
*   **`trainer.py`** — Модуль алгоритмической оптимизации. Загружает размеченный эталон (`golden.csv`) и с помощью алгоритма `BootstrapFewShot` обучает LLM выдавать строгие категориальные ответы (в 1-2 слова) вместо семантического шума. Сохраняет оптимизированную модель в JSON.
*   **`extractor.py`** — Модуль массового извлечения. Применяет обученную модель к сотням/тысячам неразмеченных статей. Включает механизмы построчного сохранения (Append) и автоматического возобновления работы при обрыве связи.
*   **`evaluator.py`** — Модуль независимой научной валидации. Проводит "слепой" тест оптимизированной модели на отложенной выборке (`exam.csv`) и рассчитывает метрики межэкспертной надежности (включая Каппу Коэна).
*   **`pipeline.py`** — Главный управляющий скрипт (Конвейер). Дирижирует всеми модулями в строгой академической последовательности.

## 🚀 Инструкция по запуску

**Шаг 1. Настройка**
Откройте `config.py` и впишите ваш API-ключ, а также проверьте пути к файлам.

**Шаг 2. Создание независимых выборок**
Запустите `sampler.py`. Скрипт вырежет 60 случайных статей из вашей общей базы и создаст два файла: `golden.csv` и `exam.csv`. 
*Откройте эти файлы в Excel и вручную заполните пустые колонки целевыми терминами (строго в 1-2 слова).*

**Шаг 3. Запуск конвейера**
После того как вы разметили обучающий и экзаменационный файлы, запустите главный скрипт:
```bash
python pipeline.py
